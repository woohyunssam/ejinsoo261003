# 컴퓨터가 이해하는 세상: 이진수 알아보기

2026 광주 수학과학축전 체험용 웹앱입니다.

- 표지: 컴퓨터 친구의 인사와 0·1 버튼
- 1단계: 숫자 0~9 찾기, 자동 세기, 십진수 알아보기
- 2단계: 부스 도우미의 안내로 오프라인 웹툰 읽기
- 3단계: 십진수와 이진수 함께 세기, 받아올림 애니메이션

웹툰 자체는 앱에 포함되지 않습니다. 읽기 완료 버튼으로 3단계에 진입합니다.
애니메이션은 시작, 일시정지, 이어 보기, 다시 보기를 지원합니다.
12와 20은 받아올림 과정을 보여주는 임시 표현이며, 사용할 수 없는 숫자 2에 X가 표시됩니다.

## 실행과 GitHub Pages

index.html과 computer.png를 같은 폴더에 두고 index.html을 브라우저에서 엽니다.
설치나 빌드는 필요하지 않습니다.
GitHub 저장소 루트에 파일을 올린 뒤 Settings → Pages에서 업로드한 브랜치와 / (root)를 선택합니다.
